# 知间真实学习前端交付记录

日期：2026-10-14。范围仅 `web/`；未修改服务器、金标准、原型或商城项目。

## 已实现

- React/TypeScript/Vite 六页：学习首页、我的试卷、老师课堂、找题、知识关系、学习记录。共享原型的青色、冷中性表面、字体、控件、画布、老师侧栏和明暗外观。中文使用本机打包的完整分块 Noto Sans SC Variable；Manrope 延续原型本地拉丁字体；公式为 KaTeX。
- 上传图片/PDF或导入用户样卷，真实调用 API，显示任务阶段、失败说明、取消请求和重试。任务失败保留原页；零题面时显示真实原图而不预置题号、答案或小问。失败任务可跨刷新重试。
- 题面与原图区域并排校对，能修改共同题干、图注、选项和每个小问，增加/删除小问；有缺项不能确认。修改和会话均使用版本号，409 不静默覆盖草稿。
- 当前版本全部小问通过完整性核验后才能打开正式老师课。每小问依次呈现所求、已知、先备、选方法、步骤及理由、公式、结论检验、易错和收束。不需强制作答，也不要求先探索。
- 受控数轴、三角形点阵组件共用确定计算函数。老师示范使用固定默认参数；孩子探索参数独立保存；a=-3合并 A=B 标签。数轴采用实际宽度和最多五个刻度，必要标签保持屏幕字号。
- 为什么、从基础、换种讲法及自由追问调用真实 `/ask`，传当前题面版本、课程版本、小问、步骤、模式及参数快照；快照补充屏幕实际的默认或当前 x/a/rows。未核验答复不作为正式解释。历史追问来自 API，旧版答疑清楚标注。
- 学习记录区分孩子原话、系统观察和读过主线；不会把任一事实叫作掌握。逐小问主线阅读需经过各个讲解片段才记录，不用一次点击宣称全题学习完成。
- GET/PUT session 保存小问、步骤、模式、参数、原话、疑问草稿和返回位置。本机未同步草稿跨刷新保留；服务器确认后才显示已保存；冲突可选择本机或服务器现场。恢复不自动发声。
- 找题使用当前卷真实题面、题号和知识标签关键词匹配；知识页只展示当前卷标签索引，不宣称已经接入 RAG 或核验知识拓扑。
