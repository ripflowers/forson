# 第26题：知识驱动动画与 Codex 备课资源

本轮把已有第26题的核验教案与真实配音作为基线，增加能够解释数学关系的 Remotion 动画，并跑通“导出教学上下文 → Codex 制作资源包 → 本机校验导入 → 课堂播放 → 视频冻结资源”的路径。没有为了制作动画调用 DeepSeek，也没有重新生成教案或配音。

## 教学动作

| 阶段 | 要让孩子看明白 | 动画与板书 |
| --- | --- | --- |
| 观察规律 | 序号、行数、点数是三个量 | 新行依次进入，同步显示新增点数和累计总数 |
| 小例选方法 | 相同部分能一一对应 | 比较第6个和第4个，前四行分别有10点；配对标记后留下5、6两行 |
| 表示规律 | 每行对应和式中的一个加数 | 点阵行号、逐项求和、累计表同步突出；以6行示意一般n行 |
| 展开原题 | 大图也能按结构表示 | 两个相同的22行253点省略块，以及真实绘制的23、24两行47枚石子 |
| 求差 | 行数差2不等于点数差 | 共同块同时变淡并留轮廓，新增两行分离，连接23+24；不把正确的24−22=2打叉 |
| 独立检验 | 复算有另一条依据 | 先看通式，再分别代入24、22得到300、253，最后作差 |
| 收束迁移 | 带走解题方法 | 观察、表示、找共同、算新增、检验的知识路线依次连起 |

空间示意采用SVG球形石子、投影与有厚度的共同块，是2.5D表现，不是真实WebGL三维模型。平面数点保留相同数量和数学关系。暂不加入旋转镜头、三角锥或遮挡点数的堆叠；它们不能帮助这道题解释求差。

## 时间线与交互

所有动画读取现有声音的canonical `visualFrame`，没有额外计时器或CSS动画驱动教学状态。口述的固定窗口保持静态；任意拖动、暂停、倍速和视频导出都从同一帧计算画面。减少动画偏好直接显示完整关系。

空间/平面切换仅更新画面参数，不重建Player。导入资源先暂停声音与板书，仍保留原准确帧。提问、探索继续使用既有暂停机制；本轮没有发起新的模型答疑调用。原题点阵与小例有持续标签，省略块不冒充只有22个点。

公式账本只保留已经推导完的步骤，当前结果在对应视觉窗口完成后加入。资源课堂右侧展示当前知识点的含义与适用理由，避免进入阶段时直接展示整个步骤的最终答案。

## 备课与导入

课堂右侧“老师备课台”可导出本小问资料和导入JSON资源包。命令行等价流程：

```bash
.venv/bin/python scripts/teaching_resources.py export-context \
  --question-id 80abf784-834c-4ef1-89dc-b3309b4ec9cd \
  --part-id main --out data/runtime/q26-teaching-context.json

.venv/bin/python scripts/teaching_resources.py import resources/codex/q26-motion-pack.json
```

交给Codex的制作要求：读取导出的原题、已核验教案及精确模板顺序；梳理每阶段的知识点、观察重点与图像解释；输出符合`MotionPackInput`的纯JSON。不要改题、改答案或加入新教学步骤，不要输出脚本、HTML、文件路径或外链。`target`须原样保留。示例资源包在`resources/codex/q26-motion-pack.json`，它绑定当前本机样本的题面r4/教案v3，不能直接用于其他题或新版本。

导出资料包含原题及教案，仅写入用户指定的本机文件。CLI只连接本机回环API，不读取密钥，不自行调用Codex或DeepSeek。当前资源包是本次Codex编写并由本机校验的产物，不冒称新一轮模型核验或教师审核。

当前可导入的模板是第26题七阶段三角形数，以及已有数轴距离模板的阶段知识说明。新增学科、新数学场景或新的动画构件仍需实现对应的受控组件与数学验证，不能通过上传任意代码执行。纯JSON资源的作用是将已实现动画、知识点和教案阶段可靠绑定；并非任意题目都已自动生成动画。

## 数据与版本

每个包包含`schemaVersion/title/subject/author/target/concepts/stages`；本机补充`id/createdAt/packHash`。`target`绑定题目ID、题面revision、教案version、小问ID与已批准教案内容SHA256。导入校验完整阶段、固定模板顺序和知识点引用；旧版本、伪造摘要、重复或缺失阶段、额外脚本字段会被拒绝。

资源存在`data/runtime/motion-resources`私有目录。导入不修改教案，不更换已缓存的29条配音。导出视频同时冻结资源包和视角，避免后续导入改变正在制作的视频。没有资源包的课程继续使用原有教学画面。

API：

- `GET /api/questions/{id}/teaching-context?lessonVersion=&partId=`：备课资料和模板约束。
- `POST /api/questions/{id}/motion-resources`：校验并保存纯JSON包。
- `GET /api/questions/{id}/motion-resource?lessonVersion=&partId=`：当前精确版本包或null。
- `GET /api/motion-resources/{id}`：读取已保存包。
- `POST /api/questions/{id}/videos`增加可选`motionPackId`、`motionView`；不传包时保留原流程。
