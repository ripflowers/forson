# 从功能堆叠到一条清楚的学习主线

2026-10-15 · 已实现的本机课堂改版

本轮沿用已核验的整卷教案、Remotion 动画资源和第26题配音，不重新生成解题内容。目标是让初次使用的人能回答：这题问什么、老师讲到哪里、我下一步可以做什么。孩子是否因此理解得更好，仍需实际试用，不能用观看时间或一次预测正确代替。

## 参考与取舍

- [Brilliant：互动题的使用方式](https://brilliant.org/help/features/how-do-i-use-interactives-on-brilliant/)：可操作的图形、表达式输入和即时反馈。采用“操作与反馈在同一处”的原则，探索不再只是拖动滑杆看答案。
- [Brilliant：共享画布中的老师](https://brilliant.org/)：老师与学习者围绕同一块画布开展引导。采用单一主画布，不复制品牌视觉或宣称同等教学效果。
- [GeoGebra Math Practice 官方帮助](https://help.geogebra.org/hc/en-us/articles/15294377044381-Students-Learn-with-GeoGebra-Math-Practice)：提示、具体操作与后续步骤相衔接。采用先观察、按需提示、再验证的交互，不强制用户每一步都点击继续。

不再同时铺开阶段标题、完整老师稿、累计板书、知识标签、答疑、笔记、导出和备课。新版保留一份当前讲解，其他信息在使用时打开。

## 用户旅程

1. **首页知道下一件事。** 当前试卷与第几题是真实数据；已就绪进入课堂，未校对或缺条件进入试卷校对。随后展示“上传并校对 → 跟老师学 → 回顾发现”三步入口。
2. **先看到任务。** 课堂显示本题所求，旁边可以展开完整题面、图注和选项；直接切题，不需要退出课堂寻找题号。多小问仍分别选择。
3. **老师连续演示。** 一个开始/继续/暂停主按钮紧邻画布上方。路线显示当前位置，允许主动回看，但播放会自动前进。画布保留动画与同步口述；没有配音的题目展示当前教学文字。
4. **有目的地探索。** “跟老师学 / 动手试一试”共享课堂位置。进入探索冻结原帧，返回仍停在原处，由学习者继续播放。
5. **按需得到帮助。** 问老师、笔记、板书和资料打开独立面板。关闭面板可用关闭按钮或 Escape；移动端也保留板书入口。
6. **留下有来源的记录。** 原话、系统观察、观看主线仍分别保存；不自动标为掌握。

## 探索的教学结构

三角形数采用“从 n−2 行长到 n 行，多了多少颗？”的小任务。灰色表示原有部分，橙色表示新增两行。孩子可以改变 n（2–8），输入预测、查看提示、重新尝试。错误反馈指出应数哪两行，正确反馈用 (n−1)+n 解释。改变行数清除上一轮反馈，避免旧答案冒充新题验证。原题的23+24=47放在“把发现用回原题”中，默认不展开。预测只在本地核算；明确保存后进入观察记录，含预测值与场景。

数轴探索给出“移动到两点之间，再移到外面”的观察任务。提供两个端点、中间、区间外快捷位置，距离与总和即时变化。保持闭区间端点成立、区间外增加两倍绕行距离等原数学约束。

## 状态与完整性约束

- Remotion Player 在探索和面板切换时保持挂载，视角切换不改变播放 key。
- 提问先冻结音轨与帧，再记录现场。正在播课时的已核验有声补讲结束，可以从原帧续讲；原来暂停的课不会擅自续播。
- 无配音的文字答疑保持暂停，读完后明确点击继续，避免答案刚出现就被面板关闭。
- 主动关闭答疑会停止补讲，并使尚未返回的请求失去继续播放权限，避免界面关闭后突然发声。
- 切题、切小问、离开页面、隐藏窗口、保存冲突仍暂停；冲突和重试入口留在课堂外层，不藏在笔记里。
- 新进入的课堂从暂停状态开始。开始后自动演进；刷新仍按既有会话恢复步骤，不宣称逐帧刷新恢复。
- 普通无动画题保留完整的条件、基础、方法、每一步解释与原因、结论、检验、误区和总结。只改变呈现位置，不删教案内容。
- 网页精简限定 `canvasOnly`；视频的布局、字幕、声音时间线与快照版本校验沿用原实现。视频导出和 Codex 资源导入仍在“资料”中。

## 对抗性检查与修复

| 质疑 | 已实施的处理 |
| --- | --- |
| 不知道正在解决什么 | 所求始终在画布上方；完整题面邻近展开 |
| 看哪里都像主内容 | 只显示一份当前讲解；完整板书按需打开 |
| 只能不断点击下一步 | 单一时间线自动讲授，路线仅用于定位和回看 |
| 只是好看的动画，孩子没有思考 | 明确观察任务、可选预测、定位到具体行的反馈 |
| 手机找不到完整理由 | 画布下方保留板书入口 |
| 关闭答疑后还在说话 | 主动关闭清理语音和异步恢复意图 |
| 文字回答没读完就继续 | 无声答疑要求读完后明确继续 |
| 手机上整页横向溢出 | 修正课堂网格的最小宽度，320px实际检查 |
| 看完就算会了 | 原事件语义不变，不写掌握结论 |
