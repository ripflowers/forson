# 两张原照的真实 OCR 独立核对

核对日期：2026-10-14。对象：真实 DeepSeek 输出 `data/runtime/evidence/extracted-paper-raw.json` 与 `data/sample-images/page-1.jpg`、`page-2.jpg` 的印刷题面。两张原照均逆时针旋转 90° 后逐题阅读；第7、8、11、15、17、27题额外放大核对。`data/sample_manifest.json` 只作独立验收参考，没有被当成模型识别结果。本核对没有修改原始 OCR 或数据库。

模型识别出了 **27个题号、39个叶子小问**，但这不等于题面识别正确：**11题有影响题意的错误**，第24题另有公式分隔符显示问题。第11题实际缺少完整定义，应阻止正式讲解；其余26题、38个叶子小问在人工校对后才可进入课程生成。

## 原题定位也存在错误

`sourceRegions` 使用旋转后的完整照片2275×1279的归一化坐标。raw不仅框偏宽：它多处没有覆盖对应题面，并且第20至27题还保留不相关左列框。可复核的例子：

- 第13题raw框纵向约383至486px，实际题面约523至558px，题面不在框内。
- 第23题raw第二框约1048至1240px，实际题面约781至885px，框主要是下方空白。
- 第27题raw右列第二框约997至1279px，实际题面约695至878px，题面不在框内。
- 第2题的数轴图在正文上方，raw正文框没有包含它；第17题raw框未包含位于正文下方的印刷数轴图。

所以“可回看原题截图”不能只验证URL返回200。当前题面PATCH不接收`sourceRegions`，本次核对没有越过接口私改数据库。提案另附27题人工视觉定位参考，需实现校正或修复坐标映射后再验证。它们的来源必须记作人工校对，不能冒充AI原生准确定位。

## 校对提案与保留原则

`data/runtime/evidence/ocr-calibration-proposals.json`：

- `questions`含27项，每项保留现有稳定题目/小问ID，仅对错误字段给最小PATCH；无问题题只确认现有题面。第11题`confirm=false`且保留缺项。
- 每题`sourceRegionsProposal`及汇总`sourceRegionCorrections`为人工视觉定位参考；它们不是已经应用的状态。27题的33个提议区域已逐一裁图目检，覆盖对应正文、选项、小问与印刷图。目检拼图保存于`data/runtime/evidence/source-region-proposals-visual-check.jpg`。
- 原始真实输出文件完整保留。提案没有标准答案、讲义或伪造OCR结果，不会把人工校对误称为模型识别成功。

补充复核：之前工具嵌套JSON显示使LaTeX反斜杠看起来被双转义；实际逐字符检查只有一个反斜杠，因此**没有重写这些正确字段**。唯一公式分隔符修正是第24题。

本审计证明的是两张照片题意的人工视觉核对与明确的校对差异，尚不证明真实生成的老师讲义逐问正确，也不证明孩子学会；后续课程与互动验收需独立进行。
