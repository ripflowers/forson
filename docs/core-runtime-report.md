## 交付范围

本机可运行的核心版位于 `zhijian-learning-app`，页面 `http://127.0.0.1:5178`，服务 `127.0.0.1:8787`，专用Postgres `127.0.0.1:55432`。服务只监听回环地址。实现整卷原图保存、真实AI识别、题面及来源圈选校对、逐小问老师讲解、两种数学互动组件、现场追问、学习笔记与记录恢复。

沿用最终设计的知间品牌、石墨文字、青色重点、浅色学习画布、局部深色外观、中文完整字体及统一数学排版。老师主线包含读题、条件、基础、选方法、逐步讲解与理由、答案、检验、易错及方法收束。孩子可直接看完讲解，按需探索或追问；看过或求助不自动计为掌握。

本轮没有实现视频导出、实际配音、多学科专用场景、跨题库向量RAG、多家庭账号或生产部署。当前找题为本卷题意/知识点/题号的关键词匹配和状态过滤；知识关系为实际知识标签关联，未把标签共现冒称已核验的先备拓扑。其他新卷可真实提取与校对，但当前自动发布门禁的独立数学基准只覆盖这两张样卷。

## 真实AI与内容门禁

使用用户本机DeepSeek密钥，实际认证成功。视觉提取为 `deepseek-flash`，文本课程与二审为 `deepseek-v4-pro`。后台高推理，追问及答疑复核低推理；整卷每批6题，全局请求最多8并发，任务调度最多2个job。具体参数与官方依据见 `deepseek-integration.md`。

第一次课程生成只接收已确认题面，不接收预期答案或参考推导。生成后才读取独立基准，检查答案、全部小问、九个教学字段、每个实际步骤的解释/理由/公式、二审原文引用和场景参数。模型只能输出数据，不能执行JS/HTML。每次自动修复最多一次，保留首次输出及失败类别；修复反馈不传参考答案与参考解法。

首轮Flash文本虽有自动ready，独立通读发现幂比较、符号、方法段结论、举例代证明和边界问题，全部撤回并保留失败历史。切换Pro后也未把自动ready当最终结论：第1/5/10/23题的误导性短句被再次撤回。二审提示补查未经题设给定的近远关系、对称中心、易错提示的前提，以及有符号的和与其绝对值的区别。

独立基准也接受充分的等价初中证明：第3题可一般推出b>1/2；第10题可用−c<0<−a否定错误链式不等式，无需强制额外全链条或提及手写选项；第17题判符号只要求数学完整，无需强制预告下一问；第16题接受完整分段增减证明；第23题接受完整假分数约分法，不强制拆项法或小数表述。这些调整不改变原题、答案或必要数学条件，也不向生成器提供解答。

最终26个完整题目的38个叶小问均为当前题面版本的ready课程。最后两题的重新生成任务 `a25ee71e-9b04-41ea-b259-a0c8239b7497` 成功完成2/2；此前失败任务与撤回的课程均保留。独立审阅者逐字段读取实际生成内容，核查数学推理、条件、边界、教学步骤、检验、易错提示与收束，没有把接口ready作为内容通过的依据。

## 验收界限

此轮目标是这份真实试卷的完整老师流程，不是宣称任意试卷OCR可靠。独立内容审读发现自动审核仍可能误放或误拒，已有失败保留、课程撤回与重新生成闭环。缺失题面必须补全；教师角色和图文交互已实现，孩子实际理解、迁移和延迟独立做对仍需后续真实孩子使用验证。
