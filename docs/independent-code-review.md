## 已确认的正确边界

- **Static**：生成教案的调用只收到已确认题面；`sample_gold()` 在独立生成结果返回后才读取参考清单。原图金标准没有预装进前端充当识别结果。参考清单为 27 个主题号、39 个叶小问；第 15 题结果为 −24。
- **Static / Test**：`check_lesson()` 分别检查当前输入、叶小问覆盖、答案值、必要教学字段；未确认题面、漏小问、空理由和旧版本不可正式就绪。理由审核独立于答案比较，不能用答案正确替代理由。
- **Static / Test**：课程发布要求相同题面版本、运行任务、有效 lease 及该题当前生成 job/lease。修改题面使旧课失效，提取保存也已加入取消与 lease 检查。
- **Static**：学习事件区分 learner、system-observation、system。原话、系统观察和读过主线分别标记，不自动推断掌握。会话服务器成功保存与本机待同步草稿分别显示，409 冲突保留本机输入。
- **Static**：API 密钥留在服务端；返回及 AI 请求留证排除密钥、请求头和 base64 原图。错误不返回供应方正文或数据库连接详情。公式采用 KaTeX `trust:false`；互动仅接受允许的组件参数，不执行模型脚本。
- **Static**：无密钥保存原图、失败配置任务、retry 和历史 asks 路由已实现；缺密钥不生成模拟题面。原图已补入 Git 忽略。

## 首轮真实 OCR 独立内容审核

**Actual API Content · 未通过题面完整性验收。** 只读脚本已取得 27 个主题号；没有课程就绪。按原图人工清单逐题审读，至少下列 11 个题号存在影响数学条件的错误。这里记录第一次识别的真实失败，不能在人工修订后删掉并声称模型一次准确识别。

| 题号 | 首轮真实提取问题 | 校对必须恢复的原题条件 |
|---|---|---|
| 1 | b 被记在 1 和 2 之间。 | b 在 0 和 1 之间。 |
| 2 | 图注只列 A/B/C/D，缺 a/b 的位置。 | 全顺序 A、a、B、C、b、D，并保留 B 更靠近 a、C 更靠近 b 的图示关系。 |
| 3 | 无刻度图被添加 A 在 −1~0、B 在 0~1 的条件。 | 图只给 A 在 B 左边，没有原点与具体刻度；不得虚构区间。 |
| 4 | 图点顺序变为 O/C/A/B，缺固定坐标。 | A=−5，A<C<O，O=0，B=5。 |

其余题目的数学文字条件在首轮对照中暂未发现差异，这不是字符级 OCR 准确率统计，也不是对讲义正确性的通过结论。特别是题号和叶小问数量齐全，仍会漏共同条件、误读图点或编造定义。正式课程应先逐图确认题面，不能依赖 missingFields 为空自动推断准确。

## 校对后首轮真实教学包审核

**Actual Model Content · 尚未就绪。** 独立阅读 `q19-first-lesson.json`、`q26-first-lesson.json` 的实际讲义与审核结果，未以状态旗标代替数学推理检查。

- 第19题(1)：把绝对值读成到 −1/2 的距离，区间上总长3、两侧多走往返，正确得出最小值3及完整闭区间 [−1,2]。包含端点验算。
- 第19题(2)①：固定点 −2/4，最小值6，讲义正文与方法收束说明整个含端点区间。数学内容正确，但机器结论只保存数字6，缺独立校验要求的 minimum / attainedWhen 对象，阻断属于结构完整性要求。
- 第19题(2)②：先排除中间区间，再分别在 x<−2 与 x>4 化简绝对值，得到 −3、5，并检验范围与代回。这是正确完整的初中分段代数解法；不必强制照抄“多2，所以单程1”的几何措辞。不过二审把源句加省略号后当逐字 quote，证据门禁正确拒绝。
- 第19题(2)③：从固定点 −a/3 推出最小值 |a+3|，求 a=−1/−5，两类分别验算取得区间，文字数学正确；但场景参数 a=−1 时 left=−3，应为 −a=1，图式与讲义矛盾，必须阻断。
- 第19题所有 scene 用了 type 而不是组件契约 kind；不自动执行或静默改模型数据。最小值公式将下标挂在第二个绝对值上会有记号歧义，后续应优先用“minₓ(整个表达式)”清楚表示。
- 第26题：T₂₄=300、T₂₂=253、差47，检验中的新增23/24两行及23+24=47均正确。实际二审因“认为/承认”、标点、LaTeX与文字格式、同义图注误判 inputEquivalent=false；这是误拒，不是讲义数学错误。审核提示应只拒尚未解决的数学条件矛盾，继续保留所有 true 与问题必须一致的门禁。

以上两份首次生成都被保留为 needs_repair，没有因为答案正确就宣称课程可用。优化教学呈现时，第26题可优先示范消去共同1~22行，再用总和公式作独立检验；这一建议不否定原实际讲义的数学正确性。
